## 2. 迁移审查结论

SQL 合集 326 个：同名同字节 172 个，同名不同内容 3 个，本项目独有 30 个，目标独有 121 个。完整名称、当前 runner 口径 SHA256、DDL/DML 提示见 `migration-inventory.json`；人工审查表见 `MIGRATION_REVIEW.md`。

三个同名差异为 001/002/003 首行品牌注释；当前源码比较已确认仅该注释不同。建议保留本项目已发布文件字节，避免 checksum 不匹配。不需要为了这三个注释新增数据库操作，但仍须核对生产 schema_migrations 实际记录。

其余 30 个定制迁移默认全部保留原名原字节；121 个上游新增迁移逐项审查，不能整体宣称安全。已有文件名主键允许相同数字前缀并存，但须检查依赖顺序。优先复核：

- 160 冻结余额、170/172/217 视频计费与模型价格：与定制扣费/退款及市场价优先级交互。
- 172 composite 路由、224/227 国产平台配额/路由：与模型级失败隔离及分组权限交互。
- 221 分组模型定价：与 `model_marketplace_*`、`upstream_pricing` 的展示/计费来源分离。
- 240 佣金流水 operation_id、241 支付赠送金额：与定制返利、结算、精度及重复回调交互。
- 238 清理无限配额、242 删除平台约束、235/236 白名单修复、220 清理视频配置：检查数据删除/重写范围。
- 190 及所有 `_notx.sql`：检查建索引前重复值、失效索引、锁与容量。
- 243–245 Gemini 显式缓存：与自定义响应缓存分开命名、授权与计费。

每个目标独有文件都需要填写：依赖、是否影响同一业务表、生产现值、预期变更、锁预算、失败恢复、验证 SQL。当前自动表提供初筛素材，生产项均标为未验证，不作为上线许可。
